# QA 問題分類法 (QA Issue Taxonomy)

## 嚴重程度等級 (Severity Levels)

| 嚴重程度 | 定義 | 範例 |
|----------|------------|----------|
| **關鍵 (critical)** | 阻礙核心工作流、造成數據遺失，或導致應用程式崩潰 | 表單提交導致錯誤頁面、結帳流程損壞、未經確認即刪除數據 |
| **高 (high)** | 主要功能損壞或無法使用，且無替代方案 | 搜尋回傳錯誤結果、檔案上傳靜默失敗、身份驗證重導向循環 |
| **中 (medium)** | 功能可運作但有明顯問題，存在替代方案 | 頁面載入緩慢 (>5s)、表單缺失驗證但提交仍成功、僅在行動版佈局損壞 |
| **低 (low)** | 微小的視覺或磨光問題 | 頁尾有錯字、1px 的對齊問題、懸停狀態不一致 |

## 類別 (Categories)

### 1. 視覺/UI (Visual/UI)
- 佈局損壞（元素重疊、文字被裁剪、出現水平捲軸）
- 圖片損壞或缺失
- 錯誤的 z-index（元素出現在其他元素後方）
- 字體/顏色不一致
- 動畫異常（卡頓、過渡不完整）
- 對齊問題（偏離網格、間距不均）
- 深色模式 / 主題相關問題

### 2. 功能 (Functional)
- 死連結（404、指向錯誤目的地）
- 死按鈕（點擊無反應）
- 表單驗證（缺失、錯誤、被繞過）
- 錯誤的重導向
- 狀態未持久化（重新整理或點擊返回鍵後數據遺失）
- 競態條件（重複提交、數據過時）
- 搜尋回傳錯誤或無結果

### 3. UX
- 導航令人困惑（無麵包屑、進入死胡同）
- 缺失載入指示器（用戶不知道操作正在進行中）
- 互動響應緩慢 (>500ms 且無反饋)
- 錯誤訊息不明確（僅顯示「出錯了」而無細節）
- 執行破壞性動作前無確認提示
- 各頁面間的互動模式不一致
- 死胡同（無返回路徑、無後續動作）

### 4. 內容 (Content)
- 錯字與語法錯誤
- 過時或錯誤的文字
- 遺留的預留位置 / lorem ipsum 文字
- 文字被截斷（未經省略號或「更多」處理即切斷）
- 按鈕或表單欄位的標籤錯誤
- 缺失或無助益的空白狀態

### 5. 效能 (Performance)
- 頁面載入緩慢 (>3 秒)
- 捲動卡頓（掉幀）
- 佈局位移 (Layout shifts)（載入後內容跳動）
- 過多的網路請求（單一頁面 >50 個）
- 過大且未經優化的圖片
- 阻塞性 JavaScript（頁面載入期間無響應）

### 6. 控制台/錯誤 (Console/Errors)
- JavaScript 異常（未捕捉的錯誤）
- 失敗的網路請求 (4xx, 5xx)
- 棄用警告 (Deprecation warnings)（未來可能損壞）
- CORS 錯誤
- 混合內容警告 (Mixed content warnings)（HTTPS 頁面中的 HTTP 資源）
- CSP 違反

### 7. 無障礙 (Accessibility)
- 圖片缺失 alt 文字
- 未標註的表單輸入框
- 鍵盤導航損壞（無法透過 tab 切換元素）
- 焦點陷阱（無法跳出彈窗或下拉選單）
- 缺失或錯誤的 ARIA 屬性
- 顏色對比度不足
- 螢幕閱讀器無法讀取內容

## 逐頁探索清單 (Per-Page Exploration Checklist)

在 QA 會話中，針對每一頁：

1. **視覺掃描** — 擷取標註截圖 (`snapshot -i -a -o`)。尋找佈局問題、圖片損壞、對齊問題。
2. **互動元素** — 點擊每個按鈕、連結與控制項。每個動作是否符合預期？
3. **表單** — 填寫並提交。測試空白提交、無效數據、邊際情況（長文字、特殊字元）。
4. **導航** — 檢查所有進出路徑。麵包屑、返回鍵、深層連結 (deep links)、行動版選單。
5. **狀態** — 檢查空白狀態、載入狀態、錯誤狀態、全量/溢出狀態。
6. **控制台** — 互動後執行 `console --errors`。是否有新的 JS 錯誤或失敗的請求？
7. **響應式** — 若有需要，檢查行動版與平板版視窗。
8. **身份驗證邊界** — 登出後會發生什麼？不同用戶角色間的權限差異？
